# platform-testing-cloud-azure

Azure integration-test fixtures based on Azurite for consumers of Platform Libraries.

The fixture contract and test example are in the [Golden Platform module guide](https://github.com/BrunoBS/golden-platform/blob/docs/golden-platform-foundation/docs/libraries/modules/platform-testing-cloud-azure.md).

- [POM and dependencies](pom.xml)
- [Reactor development and verification](../../../README.md)

Integration tests require Docker. Azurite does not implement every Azure Storage identity or delegation-key operation.
