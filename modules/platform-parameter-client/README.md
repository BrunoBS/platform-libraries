# platform-parameter-client

Read-only client for published CONFIGURATION values and V1 EXPRESSION parameters in Redis.

The contracts, compatibility rules, errors, configuration, examples, and limitations are in the [Golden Platform module guide](https://github.com/BrunoBS/golden-platform/blob/docs/golden-platform-foundation/docs/libraries/modules/platform-parameter-client.md).

- [POM and dependencies](pom.xml)
- [Reactor development and verification](../../README.md)

Redis integration tests use Testcontainers and require Docker.
